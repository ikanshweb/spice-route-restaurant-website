# Spice Route Café – Restaurant Website

A warm, responsive restaurant website built with HTML, CSS and JavaScript.

**Live site:** https://spiceroute-ikansh.netlify.app

## Features
- Online menu with category filters (starters, mains, desserts)
- Table booking form that saves reservations
- WhatsApp chat button
- Customer-friendly "Our Story" section
- Fully mobile-friendly

*Concept project by Ikansh — web designer & developer.*
